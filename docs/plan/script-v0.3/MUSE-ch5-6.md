## 2. Kernel or not

Cut/move to web course: two-space cyclicity generality (vl05:16–20; same-space rule plus ket-bra case suffices); P2 functionals as *starting point* (vl06:24–26 — define $\rho$ first); $L^2(\mathbb{R}^3)$, „Qudit“ (21, pure forward reference); ellipse for $\pauli{x}+2\mathbb{I}$ (vl05:71–73, linear algebra only); undefined forward terms „selbstadjungiert“ (vl06:94), „Spurklassenfall“ (24).

Missing and essential: (a) textbook Born form $p_x=\abs{\braket{\phi_x}{\psi}}^2$ for pure state + projector-valued measurement — two lines from vl06:60, needed to read any other book; (b) one example where off-diagonal $x$ in $\rho$ does something (detector $\ketbra{\phi_0}{\phi_0}$), else superposition never acts; (c) differential Schrödinger/von-Neumann equation and $\hat U_{s+t}=\hat U_s\hat U_t$, $\hat U_0=\mathbb{I}$ — without them vl05:95 („Lösung der Schrödingergleichung“) is unverifiable; (d) one sentence that P0–P5 give no state-after-measurement rule, repeated measurements out of scope; (e) phase equivalence (§1m).

## 3. Against the old versions

Gains: 96/108 lines vs. 207/167; honest finite-dimensional kernel instead of delta-function position basis. Correctness: old vl06 got $\cos(t/\hbar)$ from dimensionless $\bigl(\begin{smallmatrix}0&1\\1&0\end{smallmatrix}\bigr)$ as Hamilton operator (vl06-v0.2.tex:141–153) — dimensionally wrong, fixed by $\varepsilon\pauli{x}$. Old orthogonality proof covered only distinct eigenvalues, then proceeded as if a basis existed (vl05-v0.2.tex:133–157); new text boxes the spectral theorem (vl05:54–56). Trace independence now proved; general $f(\hat A)$ replaces lone exponential; qubit ball (vl06:41) and inefficient detector (76) make POVM$\ne$projector-valued concrete vs. abstract $F(S)$ (vl06-v0.2.tex:100–111); hats separate operators from numbers.

Losses: old Postulat 2 *defined* state = density operator readably in one sentence (vl06-v0.2.tex:36); new P2 telegram style is unparsable for me (§1k) — biggest loss, at the centre. Old text distinguished invertible $S$ from unitary diagonalisation (vl05-v0.2.tex:83); new silent narrowing contradicts linear algebra (§4). Old frequency interpretation — hits/repetitions, procedure vs. apparatus, reproducibility (vl06-v0.2.tex:8–13) — compressed to two sentences (vl06:8) in exactly the operationalist course needing it. Old column-vector eigenvector computation (vl05-v0.2.tex:98–127) and explicit Taylor sum (vl06-v0.2.tex:145–158) were hand-checkable; new ket-bra algebra must be believed.

## 4. False or misleading as written

- vl05:31,49,55: $\bigl(\begin{smallmatrix}1&1\\0&2\end{smallmatrix}\bigr)$ (eigenvectors $(1,0),(1,1)$) is „nicht diagonalisierbar“ here; standardly it is — only not *unitarily*.
- vl05:73, c03-de.tex:2362: „Hauptachsen sind die Eigenvektoren, Halbachsen die Eigenwerte“ — axes are spans, lengths are $\abs{a_x}$; true only for positive 3, 1. vl05 also omits the $\mathbb{R}^2\subset\mathbb{C}^2$ restriction (stated c03-de.tex:2357).
- vl05:84: „jede Teilsumme ist ein Polynom“ does not prove series = spectral $\hat U_t$; needs evaluation on $\ket{\phi_x}$ + scalar convergence (c03-de.tex:2501–2503). True claim, invalid argument.
- vl05:57: infinite-dimensional „hermitesche Operatoren ohne Eigenvektoren“ needs *selbstadjungiert* (bounded example c03-de.tex:2384–2405) — the sloppiness vl06:94 itself warns against.
- vl06:6, c04-de.tex:28–31: „klassisch … stets Ausdruck fehlender Information“ overstates; mixed-state $\sum p_x\ketbra{\phi_x}{\phi_x}$ is precisely preparation ignorance, so the slogan fights P2.
- vl06:26: state assigns *every* operator „seinen Erwartungswert“ — non-Hermitian $\hat A$ gives complex values, no measurement expectation.
- vl06:30, c04-de.tex:208–210: „das elektromagnetische Feld koppelt immer an“, hence no isolated systems, mixed = normal case: neutrinos are uncharged; a pure total system can have mixed parts. Idealisation warning presented as empirical fact.
- vl06:32, c04-de.tex:248: „genau einen Eigenwert 1“ — also eigenvalue 0; meant: 1 with multiplicity one (image dimension, dropped from c04-de.tex:248).
- vl06:69, c04-de.tex:383: diagonal entries „als Wahrscheinlichkeiten zu lesen“ false unqualified — basis-dependent; only $\rho_{xx}=\tr(\rho\ketbra{x}{x})$ in the *measured* basis.
- vl06:88: „jede Systemsorte … durch $\hat{\mathrm{Ham}}$ charakterisiert“ unconditional; driven/open systems excluded by line 83 but not by this sentence.
- c04-de.tex:104: „Norm 1“$=\AlgSt(\Id)=1$ holds for the operator norm, never fixed in the kernel. :179–192 uses $\AlgSt(\Id)=\norm{\AlgSt}=1\Rightarrow$positiv without citation (a theorem). :400–401: $\hat F_{\Outcomes}=\Id$ conflates subset-effect with outcome-effect; the certain event is not a „Fehlschlag“.
