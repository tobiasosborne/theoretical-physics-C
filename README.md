# Theoretische Physik C

Lecture notes for the one-semester course *Theoretische Physik C* (quantum
mechanics and statistical physics) at the Leibniz Universität Hannover,
in **German** and **English**.

22 lectures: from the birth of quantum mechanics and probability theory,
through Hilbert space, operators, the postulates, the Schrödinger equation,
the standard solvable potentials, angular momentum, spin, the hydrogen atom
and identical particles, to entropy and the microcanonical and canonical
ensembles.

The notes are paired with a [lecture video series][playlist] — 25 recordings
of roughly 90 minutes each. The commentary in those lectures, which was never
written down, is folded back into the notes.

[playlist]: https://youtube.com/playlist?list=PLDfPUNusx1Epw58nW3Acp7VI-PqXCkQXf

## Repository layout

```
latex/

  TheoreticalPhysicsC.tex     English master
  tpc-style.sty               fonts, colours, theorem environments, boxes
  tpc-macros.sty              QM and statistical-physics macros

  figures/                    TikZ figures, one file each

archive/
  skript-2022/                the v0.1 LaTeX source, as it was
  skript-2021/                earlier working copy
  (compiled PDFs, student corrections, admin material and third-party
  files are kept locally only and are not part of the public repository)

scripts/
  fetch_transcripts.py        download and normalise the captions
  check_parity.py             German ↔ English structural parity

                              master and deploys build/pages/ to GitHub Pages
```

## Building

```bash
./build.sh              # both editions
./build.sh --de         # German only
./build.sh --en         # English only
./build.sh --draft      # fast single pass
./build.sh --cmfonts    # Computer Modern, no proprietary fonts
./build.sh --clean
```

Requires XeLaTeX. The full font stack is Times LT Std, Whitney and MTPro2;
`--cmfonts` builds without them.

## The two editions

The **German edition is the leading one**. Content changes are made there
first and then carried across to the English edition.

Prose differs between the two by definition, but everything that carries no
language must agree — and `ci.sh` enforces that:

| Check | What must match |
|-------|-----------------|
| structure | every lecture exists in both, and both masters `\input` it |
| sections | the same sequence of `\section` / `\subsection` / `\subsubsection` |
| maths | every display equation, symbol for symbol, after stripping `\text{…}` |
| environments | the same sequence of theorem-like environments |
| labels | the same `\label` set, so cross-references resolve in both |
| references | the same `\ref` / `\eqref` / `\cite` keys |
| figures | the same figures are included |
| eqbox | the same number of highlighted key equations |
| language | no untranslated German left in an English source |

```bash
./ci.sh                 # everything
./ci.sh --fast          # skip the PDF builds
./ci.sh --parity        # parity check alone
./ci.sh --install-hook  # run --fast on every commit
```

## Transcripts

`scripts/fetch_transcripts.py` downloads YouTube's original-language
(`de-orig`) automatic captions for all 25 lecture videos and writes a
timestamped transcript per video. Those raw captions are heavily garbled on
technical vocabulary, so `transcripts/clean/` holds a reconstruction of each
lecture: what was said, section by section, with the commentary that never
made it into the written notes marked out separately.

```bash
scripts/fetch_transcripts.py            # fetch what is missing
scripts/fetch_transcripts.py --force    # re-download everything
```
