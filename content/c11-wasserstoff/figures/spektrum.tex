% Generating formula (DERIVATION.md Result 8.2, vacuum wavelength of the internal gap, Z = 1):
%     lambda(n -> n') = h c / (E_n - E_n') = lambda_inf / (1/n'^2 - 1/n^2),
%     lambda_inf = (1 + m_e/m_p)/R_inf = (3/4) * 121.5684456173 nm = 91.17633421 nm
% (reduced mass included; the derivation gives lambda(2 -> 1) = 4(1 + m_e/m_p)/(3 R_inf) = 121.5684456173 nm
% and lambda(3 -> 2) = 656.4696063332 nm, which this formula reproduces).
% Lyman n' = 1, n = 2..12; Balmer n' = 2, n = 3..12; series limits lambda_inf n'^2 (n -> infinity).
% Greyscale: Lyman solid, Balmer dashed; both labelled directly.
